## 📖 Overview
<a id="overview"></a>

**AD ACL Scanner** is a functional tool designed for Windows that simplifies the management of access control lists (DACLs) and system access control lists (SACLs) in Active Directory. The latest version provides a comprehensive solution for generating detailed reports, facilitating easy comparisons of ACLs using USN from replication metadata.

Getting started with **AD ACL Scanner** is straightforward. You can launch it through a graphical interface without installation; simply call the script file, and you’re ready to manage your Active Directory permissions effectively. The current stable version includes all features and improvements, making it an indispensable tool for IT professionals.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **HTML Reporting** — View and save detailed reports of DACLs/SACLs to disk.
- **Explicit DACL/SACL Reporting** — Generate reports only on explicitly assigned permissions.
- **Comprehensive Object Reporting** — Report on OUs, Container Objects, or all object types.
- **Owner Reporting** — Easily identify the owner of any object.
- **Permission Filtering** — Filter permissions for specific access types or identities.

### Advanced Features:
- **Replication Metadata Usage** — Compare permissions using AD replication metadata for accuracy.
- **CSV Export** — Export DACLs/SACLs on Active Directory objects in CSV format.
- **Visual Comparison** — Compare previous results with the current configuration using color schemes to highlight differences.
- **Exchange Schema Version Check** — Added support for Exchange Server 2016 CU1.
- **Improved Performance** — Enhanced code for better handling of permissions, reducing memory issues.
